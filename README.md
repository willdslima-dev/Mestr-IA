# DevCom - Deploy Produção

Sistema de gestão com IA para pedidos, clientes e orçamentos.

## Deploy no GitHub Pages

Esta pasta contém o build de produção pronto para GitHub Pages.

### Como Ativar:

1. Faça push desta pasta para o GitHub
2. Acesse: Repositório → Settings → Pages
3. Configure:
   - **Source**: Deploy from a branch
   - **Branch**: main (ou sua branch)
   - **Folder**: /Prod (ou root se mover os arquivos)
4. Salvar e aguardar deploy (~2 minutos)

### Acesso:
Após o deploy, acesse: `https://[seu-usuario].github.io/[nome-repo]/`

### Configuração da IA (Opcional):
1. Acesse a aplicação
2. Clique em Configurações → IA
3. Insira sua chave do Google Gemini
4. A chave fica salva no navegador (localStorage)
